# GitHub Traffic Analytics Dashboard - Quick Start Guide\n\n## 🚀 Get Started in 3 Steps\n\n### Step 1: Create Your GitHub Token\n\n1. Go to https://github.com/settings/tokens/new\n2. Name it: `github-traffic-dashboard`\n3. Select these scopes:\n   - ✅ `public_repo` - Access public repositories\n   - ✅ `repo` - Full control of private repositories (if tracking private repos)\n4. Click **\"Generate token\"**\n5. **COPY** the token immediately (you won't see it again!)\n\n### Step 2: Open the Dashboard\n\nVisit: **https://sriharshaguthikonda.github.io/dashboard/**\n\n### Step 3: Enter Your Credentials\n\n1. **GitHub Username**: Enter your GitHub username (e.g., `sriharshaguthikonda`)\n2. **GitHub Token**: Paste the token you just created\n3. Click **\"Load Dashboard\"**\n4. Wait for data to load (30 seconds to 2 minutes depending on repo count)\n\n## 📊 What You'll See\n\n### Dashboard Features:\n- **Key Statistics**: Total repos, views, clones, stars\n- **Traffic Charts**: \n  - Line chart of views & clones over time\n  - Bar chart comparing repositories\n  - Doughnut chart of views vs clones ratio\n  - Horizontal bar chart of top repos\n- **Detailed Table**: All repos with metrics and links\n- **Export Options**: Download as CSV or JSON\n\n## 🔐 Security & Privacy\n\n✅ **100% Secure**\n- Your credentials are **never** sent to any server\n- Dashboard runs entirely in your browser\n- Your token is only used for GitHub API calls\n- Close the tab and all data is gone\n\n💡 **Optional**: Your username is saved in browser storage for convenience (token is NOT saved)\n\n## ⚠️ Important Notes\n\n- **Traffic data is limited to 14 days** (GitHub API limitation)\n- Your repos need actual traffic to show data\n- Repos with no traffic won't show in charts\n- Private repos require the `repo` scope in your token\n\n## 🐛 Troubleshooting\n\n| Issue | Solution |\n|-------|----------|\n| \"401 Unauthorized\" | Your token is invalid. Generate a new one |\n| \"No data\" | Repos need actual traffic. Check if repos have views/clones |\n| \"404 Not Found\" | Double-check your GitHub username |\n| Slow loading | Normal for many repos. Dashboard loads each repo sequentially |\n| Charts not showing | Refresh the page and try again |\n\n## 🎯 Advanced Tips\n\n### Track Multiple Accounts\n1. Use different browsers or private windows\n2. Each session stores its own username separately\n\n### Schedule Regular Checks\n1. Bookmark: `https://sriharshaguthikonda.github.io/dashboard/`\n2. Export data weekly to CSV/JSON for history tracking\n3. Keep token safe - never commit it to git\n\n### Share Analytics\n1. Export to JSON format\n2. Share the JSON file with team members\n3. They can view it in tools like JSON viewers online\n\n## 📚 Understanding the Metrics\n\n- **Views**: Unique page views of your repository on GitHub\n- **Clones**: Git clone operations on your repository\n- **Stars**: Number of users who starred your repository\n- **Language**: Primary programming language detected by GitHub\n\n## 🆘 Still Having Issues?\n\n1. **Check GitHub Token Scopes**\n   - Go to https://github.com/settings/tokens\n   - Click on your token\n   - Verify scopes are correct\n\n2. **Check Repository Permissions**\n   - Token must be able to access the repos\n   - Private repos need the `repo` scope\n\n3. **Clear Browser Cache**\n   - Press `Ctrl+Shift+Delete` (Chrome/Firefox)\n   - Clear cookies and cache\n   - Reload the dashboard\n\n4. **Check Browser Console**\n   - Press `F12` to open Developer Tools\n   - Go to Console tab\n   - Look for error messages\n   - Screenshot and share if reporting issues\n\n## 🎉 Success!\n\nYou should now see:\n- ✅ Dashboard loaded with all repos\n- ✅ Charts and statistics\n- ✅ Detailed table with metrics\n- ✅ Export options working\n\n**Enjoy your GitHub Analytics Dashboard!**\n\n---\n\n*Last Updated: June 2026*\n*Dashboard by sriharshaguthikonda*\n
